How to get your admin token
  1. Open GitHub’s fine-grained token page.
  2. Name it “Farewell album” and choose an expiry date.
  3. Choose Only select repositories, then farewell-album under Rahulmehtaa.
  4. Under repository permissions, give Contents Read and write access. Leave other permissions unchanged.
  5. Generate the token, copy it, and paste it above.

Your token goes directly to GitHub and stays only in this tab’s memory. Sign in again after refreshing or reopening the page. Keep the token private.

Saved notes and photos are public. Updates usually appear in a minute or two. Deleting a note removes it from the album; earlier versions remain in GitHub’s history.
